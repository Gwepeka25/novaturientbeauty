# Michelle Ihirwe — website build handoff

This repository contains the approved **Option 3: Private Sanctuary** direction for Michelle Ihirwe’s new booking website.

## Start here

- Open [`index.html`](index.html) to view the approved, self-contained visual reference.
- Give [`docs/AGENT_BUILD_PROMPT.md`](docs/AGENT_BUILD_PROMPT.md) to the implementation agent.
- Use the original photography in [`assets/`](assets/) and the verified source price list in [`reference/pricing-list.pdf`](reference/pricing-list.pdf).

The reference page establishes the required composition, feeling, hierarchy, type direction, spacing, photography treatment, and core wording. It is not the finished booking system. The implementation must preserve this design while adding real booking, review, content-management, and business-management features.

## Approved direction

- Michelle leads the brand; **Novaturient Beauty** is secondary.
- Immersive and editorial rather than clinical or template-like.
- A full-office photographic hero with a deep forest overlay, oversized serif headline, warm-gold actions, and Michelle’s profile card.
- Calm, warm, discreet, and highly professional.
- Real photography only—no stock or AI-generated people.
- Short, reassuring copy with a clear path to booking.
- In-person sessions in Jette and online sessions.
- Cash payment only for now; online-session arrangements are confirmed after booking.
